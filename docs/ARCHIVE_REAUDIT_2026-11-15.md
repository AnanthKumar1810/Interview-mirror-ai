# Archive re-audit — 15 November 2026

## Scope

This audit used only the supplied `InterviewMirror-ClearView-realtime.zip` archive. The original ZIP was not modified. Fixes described below were applied to a separate extracted copy.

## Findings and changes

- The backend uses FastAPI with a WebSocket interview route and Gnani Prisma/Timbre adapters. The ClearView frontend lives under `frontend/`; the root `static/` client and frontend are two UI implementations, so operators must use the documented frontend/backend development commands together.
- The active interview scoring and follow-up path is deterministic. The available project configuration does not prove access to a Gnani semantic evaluator or translation service.
- The calibration and practice data are not a human-reviewed gold set. Practice labels are synthetic/unreviewed and references are null. JorGPT and Mohler importer code exists, but corresponding imported dataset files are not in this archive.
- The async streaming tests are marked with `pytest.mark.asyncio`, but the development requirements omitted `pytest-asyncio`. Added it to `requirements-dev.txt`.
- The GitHub Actions workflow ran only Python checks and did not validate the shipped frontend. Added a frontend CI job to install locked dependencies and run tests, lint, and build.
- README test-status text conflicted with the newer integration report and was rewritten to avoid stale test counts or implying tests prove live provider access.

## Checks performed in this environment

- Python compile check: passed for project source directories.
- Pytest collection: 246 tests collected.
- Pytest execution: did not complete in this environment. The isolated `tests/test_gnani_streaming.py` run stalled at `test_prisma_client_config_and_api_key_in_headers`; it was stopped. Treat the suite as unverified until it completes in a clean environment.
- Frontend tests, lint, and build: not run because frontend dependencies were not installed in this audit environment.
- Real Gnani access: not tested from this archive. The ZIP contains no `.env`; no key was bundled, so this audit makes no live-call claim.
- Physical microphone, speaker, echo, barge-in, pause detection, and multilingual user-device behavior: not verified.

## Remaining release blockers

1. Run backend tests with the updated development requirements and fix any actual hangs or failures.
2. Install frontend dependencies and pass its CI job.
3. Verify the end-to-end flow on a physical microphone and speakers, including silence detection, barge-in, transcript timing, and next-question progression.
4. Keep speech-to-text and voice output results distinct from semantic scoring; obtain documented Gnani semantic/translation access before claiming those capabilities.
5. Collect a consented, independently human-reviewed holdout before reporting semantic accuracy or fairness metrics.

No model-quality, golden-dataset, or provider-success metric was generated by this re-audit.
